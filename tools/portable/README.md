# MewnBase Multiplayer — Windows portable

Extract the entire archive into a new folder. Start MewnBase.exe or run.bat.
Create or join a server through Multiplayer in the game menu.

The archive includes the runtime used by MewnBase.exe. Java from PATH is used
by run.bat only if MewnBase.exe is missing. Debug eval and local server/client startup
are disabled in the normal launcher.

To update, close the game first. Keep a backup of your old folder; copy your
saves folder into the new installation if you want to keep existing worlds.
No personal saves or settings are included in this release.

Known issue: the previously reported prolonged map/death slowdown has not been
reproduced. This release adds optional diagnostics, not a confirmed fix for that
specific performance incident.
