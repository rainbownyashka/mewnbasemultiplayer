# v1.0.4 — MewnBase 1.0.2 support / Поддержка MewnBase 1.0.2

## Русский

### Совместимость и исправления

- Установщик поддерживает чистые JAR MewnBase 1.0.1 и 1.0.2 и проверяет контрольную сумму до установки.
- Для 1.0.2 сохранена совместимость с его Steam API и HUD закреплённого рецепта; также сохранены прокси-тайлы построек, фильтр выгруженных чанков и открытие папки сохранения.
- В 1.0.2 launcher/Steam-классы игры не заменяются файлами от 1.0.1; версия на экране остаётся `1.0.2`.
- Установщик на русском или английском ищет игру в библиотеках Steam, стандартных папках itch.io и распространённых каталогах. Если игра не найдена, выберите корень, где есть `MewnBase.exe`, `data` и `game/desktop-1.0.jar`.

### Проверка

Оба варианта скомпилированы с Java 8 bytecode; установку и восстановление проверили на точных JAR 1.0.1 и 1.0.2. На JAR 1.0.2 прошёл запуск меню создания игрока и проверка Steam API без `NoSuchMethodError`. Для локального запуска полного 1.0.2 набора игровых ресурсов он в рабочей папке отсутствовал, поэтому этот smoke-тест использовал launcher/data 1.0.1 с JAR 1.0.2.

Меню мультиплеера пока отображается на английском; язык остального интерфейса задаётся игрой.

## English

### Compatibility and fixes

- The installer supports clean MewnBase 1.0.1 and 1.0.2 JARs and checks the exact file hash before patching.
- The 1.0.2 build keeps its Steam API and pinned-recipe HUD contract, plus its proxy-tile behavior, unloaded-chunk filter, and save-folder command.
- The game's 1.0.2 launcher/Steam classes are preserved instead of being replaced with 1.0.1 files, and the displayed game version stays `1.0.2`.
- The installer wizard is available in Russian and English. It searches Steam libraries, common itch.io folders, and usual game locations. If no install is found, select the root containing `MewnBase.exe`, `data`, and `game/desktop-1.0.jar`.

The installer and manual archives contain only the multiplayer patch. They do not include the original JAR, game assets, or MewnBase source code. During install, the original JAR is saved as `game/desktop-1.0_original.jar`. Run the installer again to restore it; the backup is retained.

For a manual install, close the game, verify the original JAR SHA-256, and copy it to `desktop-1.0_original.jar`. Add the ZIP's `com` folder to the JAR root with 7-Zip. To undo the patch, replace the JAR with the saved backup.

Clean JAR SHA-256: 1.0.1 — `9452d5588c457995599a3fb95ef6d570fa4aa2f3d367bd0dbe2d63a303272b6c`; 1.0.2 — `18d88af1c48f475d25c45a1bcf5b127071f48d771958798e5fad62e14baee517`. Do not apply a patch if the hash differs.

### Verification

Both variants compile to Java 8-compatible bytecode. Installer install/restore was verified against the exact 1.0.1 and 1.0.2 JARs. The 1.0.2 JAR reached the player-creation screen and called the Steam API without `NoSuchMethodError`. The complete 1.0.2 game asset set was not present locally, so that smoke test used the 1.0.1 launcher/data with the 1.0.2 JAR.

The multiplayer menus are currently in English; the rest of the UI follows the game's language setting.
