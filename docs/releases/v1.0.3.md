# v1.0.3 — Multiplayer fixes / исправления мультиплеера

## Русский

### Исправления

- Исправлен сбой Box2D при очистке игрока после выхода из мира.
- Хост теперь возрождается по тем же правилам, что и подключённые игроки; закрывать сервер не нужно.
- Исправлена повторная обработка смерти и анимация смерти, которая перекрывала возрождение.
- Мультиплеерные карты больше не ставят мир на паузу; незавершённое открытие карты и её ресурсы очищаются при смерти или выходе.
- Добавлена необязательная диагностика кадров для поиска просадок. Длительная остановка на карте или при смерти не воспроизвелась, поэтому она не заявляется исправленной.

Проверено на 20 локальных циклах хост/клиент и переходах Game Over в одиночной игре. Миграция сохранений или сетевого протокола не нужна.

### Установка

Скачайте [MewnBaseMP-Setup-v1.0.3.exe](https://github.com/rainbownyashka/mewnbasemultiplayer/releases/download/v1.0.3/MewnBaseMP-Setup-v1.0.3.exe) и запустите. Установщик ищет игру в библиотеках Steam и стандартных папках itch.io. Если игра не найдена, укажите папку, где находятся MewnBase.exe, data и game/desktop-1.0.jar.

Перед установкой патча создаётся и проверяется копия оригинального JAR: game/desktop-1.0_original.jar. Для восстановления запустите установщик ещё раз и выберите Restore. Резервная копия останется на месте. Установщик содержит только бинарный патч мультиплеера и не включает оригинальный JAR, игровые данные или исходники MewnBase; сохранения и настройки не меняются.

Важно: меню мультиплеера в этой версии пока отображаются на английском. Остальной интерфейс игры использует выбранный в MewnBase язык.

## English

### Fixes

- Fixed a Box2D crash during player cleanup after leaving a world.
- The host now respawns under the same rules as connected players; the server does not need to be closed.
- Fixed repeated death processing and the death animation overriding respawn.
- Multiplayer maps no longer pause the world; pending map opening and map resources are cleaned up on death or exit.
- Added optional frame diagnostics for investigating slowdowns. The prolonged map/death stall was not reproduced, so it is not claimed fixed.

Validated with 20 local host/client lifecycle cycles and single-player Game Over transitions. No save-format or network-protocol migration is required.

### Install

Download [MewnBaseMP-Setup-v1.0.3.exe](https://github.com/rainbownyashka/mewnbasemultiplayer/releases/download/v1.0.3/MewnBaseMP-Setup-v1.0.3.exe) and run it. The installer searches Steam libraries and common itch.io folders. If it does not find the game, choose the folder containing MewnBase.exe, data, and game/desktop-1.0.jar.

Before patching, the installer creates and verifies a backup of the original JAR at game/desktop-1.0_original.jar. To restore the original, run the installer again and choose Restore. The backup is retained. The installer contains only the binary multiplayer patch; it does not include the original JAR, game data, or MewnBase source code. Saves and settings are unchanged.

Note: multiplayer-specific menus in this version are currently displayed in English. The rest of the game follows the language selected in MewnBase.
