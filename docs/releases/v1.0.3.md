# v1.0.3 — multiplayer respawn and crash fixes

- Fixed the native Box2D crash caused by late player cleanup after leaving a world.
- Hosts now automatically respawn under the same rules as connected players, without closing the server.
- Fixed repeated death processing and death animation overriding respawn.
- Multiplayer maps no longer pause the world; pending map opening and map resources are cleaned up on death or exit.
- Added optional frame diagnostics for investigating slowdowns. The previously reported prolonged map/death stall was not reproduced and is not claimed fixed.

Validated with 20 local host/client lifecycle cycles and single-player Game Over transitions. No save-format or wire-protocol migration is required.

For patch-only distribution, download `MewnBaseMP-Setup-v1.0.3.exe` and run it against a purchased Steam or itch.io copy of MewnBase. The installer locates the game or asks you to choose its root folder.

Before patching, it keeps the original `game/desktop-1.0.jar` as `game/desktop-1.0_original.jar`. Run the installer again and choose restore to return to the original JAR. The setup does not include the game, saves, or settings.
